Completed contributions are integrated locally on the central planning branch.
No main merge, formal round closure or publication is claimed. The archived
checkpoint receipts in the repository's common Git coordination directory hold
exact identities, raw outputs and original approvals; this prose index does not
replace them or create runtime proof.

Each new checkpoint identifies task/wave/round, exact commit/tree/base, declared
role and owned diff, prompt SHA-256, original tier map and real executor identity,
commands and complete exit/results, counterexamples, distinct reviewer, standing
mandate reference, acceptance time and explicit handoff. Preserve all attempts.
Checkpoint kinds are accepted-design, established-counterexamples and
passing-implementation. A declared RED Inspector counterexample permits only its
Engineer handoff; all final declared acceptance must pass on the cumulative
candidate. Changed inputs invalidate affected evidence.

permits declared downstream source work under the scoped CMP-0006 procedure; it
never sets merged_as, closes a round or satisfies a publication/adopter effect.
