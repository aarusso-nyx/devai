After offline CTG-0661 acceptance, record each installed host's exact version,
schema support and help-confirmed tool/MCP disable controls. Use isolated empty
user/project configuration and record its file identities. Verify tool and MCP
inventory before invocation; --tools empty or a read-only sandbox alone is
insufficient. No inferred MCP disabling flag is prescribed in this draft.

Obtain OE-04 explicit human initiation, safe input scope and resource cap. Supply
credentials out of band. Use a distinct review instance and no shared working
context. Retain a bounded sanitized transcript, positive completion, actual zero
tool/MCP events, provider projection schema digest and canonical verdict validation.
For structured_output, extractor reply bytes are UTF-8 JSON.stringify(value)
with no trailing newline; envelope bytes and reply bytes have separately named
digests. Never label a transformed reply digest as the original envelope digest.
Any redaction, truncation, tool invocation, provider error or schema mismatch
blocks live acceptance. Both declared hosts must pass separately. The campaign
review mode remains human; a valid model verdict never ratifies a gate or effect.
