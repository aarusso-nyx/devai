closing REC-D1, not a claim that ADR-EVI-0006 already supports it. No CLI/action name,
flag, dirty-candidate exception, generator or machine write is presently available
or authorized by this packet. No constitutional weakening is proposed.

## Decision requested

Commission a source-bound machine reconciliation/bootstrap contract under upstream
Architect authority. Recommended canonical disposition: retain current main's
entire335-entry prefix; preserve exact S2/base/original chains in immutable custody;
account for every source proof line and every displaced active anchor. Current
expected recovery population is R-0025 generic7 and8 ONLY. OldS2 line 8 event stays

Existing Article 6 machine-only proof ownership and clean-candidate admission remain
binding. A new public supported mechanism must explicitly establish equivalent
source identity, role separation and fail-closed behavior for this bootstrap.
No undocumented internal call, alternate checkout hiding history, stale accepted
catalogue or bypassing the existing clean-HEAD guard is admissible.

## Contract that the design must close

1. Read-only plan binds exact repo, both parent commits, index stage1/2/3 blobs,
   main 335/S2 169/original 166/common-prefix identities, complete immutable proof
   epochs, protected legacy chain, staged source manifest and before-state hashes.
   Fail on missing/changed/ambiguous source; expected current parent heads are fixed.
2. Machine-owned proof operation retains the approved main canonical prefix and
   derives lost-anchor obligations from original receipts. Line7 uses U1's accepted
   divergent contract and original 166 receipt; line 8 uses supported newest recovery.
   No copied/resequenced source event, payload replay or historical-gap exception.
   Reject any additional orphan until a new exact population is reviewed.
3. Separate Architect-authorized inventory admission binds every resolved tracked
   source/input byte from the approved staged candidate. The only proposed unresolved
   paths are record/proofs/chain.json and law/security/authorization.json; they are
   controlled transaction dependencies, never ignored arbitrary source. All other
   unmerged/dirty/untracked executable inputs must be rejected. Existing clean-HEAD
   mode stays unchanged. Bootstrap output standing is diagnostic/source inventory,
   NEVER final native readiness or scorecard promotion.
4. Define exact registered producer/export effects, filenames, role handoffs, source
   identity tokens, output schema/provenance, retries and stale-index/HEAD refusal.
   Inspector proof authority and Architect inventory/export authority must not be
   collapsed into a silent all-powerful role. No action writes its own reference.
5. Derived authorization and PII catalogues come only from bound complete native
   bodies plus existing deterministic exporters. Preserve all shared controls and
   the two new S2 GET routes. No placeholder/stale catalogue commit declared valid.
6. Define serialized publication, crash boundaries and resumability across all
   outputs/index updates. A failure leaves unchanged pre-state or an explicit safe
   resumable phase with gates closed. Never roll back an appended proof history,
   lose main/S2 custody, or report final acceptance from a partial transaction.
7. After supported source reconciliation becomes a real clean commit, run the
   unchanged complete native producer, deterministic export verification and native
   chain verification at final exact HEAD/tree. Commit/export drift requires fresh
   final-head verification; earlier receipts retain their original identity.

## Required design acceptance

interrupted publication and replay. Unknown native output or new schema stops.

reported honestly. Final inventory/chain gates remain independent and mandatory.
