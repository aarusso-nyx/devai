   its security properties. Each later safety assertion also needs a corresponding
   fault/missing-check counterexample or controlled implementation defect.
3. Engineer changes only the nine source paths and never edits Inspector tests.
   Implement the prospective projection and host-owned review protocol first;
   exercise publication only in disposable fixtures. Stop at an additional path,
   output, runtime capability, authority interpretation or unsupported boundary.
4. Inspector independently runs the smallest selected local checks through the
   existing validation runner, one worker where subprocess tests contend. Retain
   raw argv, roles, source hashes, status/streams, before/after file inventories,
   exact bytes, phase transitions, deterministic clock/race/fault scheduling and
   publication identity. Do not extend timeouts, lower thresholds, skip tests,
   truncate epochs, alter existing assertions or create real binding files.
5. Independent exact-diff review verifies all 19 paths and generated effects, the
   protected contracts and both older packet manifests. Run affected required
   checks against fetched base when a provisioned built CLI is separately
   authorized/available. Exact-head CI and source publication/integration authority
   remain separate gates. Heavy RC/build/coverage and installed-package validation
   require their own later resource/effect plan; no lease or release is inferred.

## Public refusal contract proposed

Use the current structured refusal envelope and admitted routing-authority refusal
exit **2** for new review refusals; no new exit class is introduced. Existing
publication infrastructure/indeterminate errors retain their current semantics and
must not be disguised as a clean refusal or success. Plain caller cancellation is
exit0 with `status=cancelled`, `binding_performed=false`, and is never an apply
receipt. Exact proposed review codes:

- `AUTHORITY_POLICY_REVIEW_SELECTION_INVALID`
- `AUTHORITY_POLICY_REVIEW_TERMINAL_REQUIRED`
- `AUTHORITY_POLICY_REVIEW_TARGET_NOT_ABSENT`
- `AUTHORITY_POLICY_REVIEW_INPUTS_UNSUPPORTED`
- `AUTHORITY_POLICY_REVIEW_STALE_INPUT`
- `AUTHORITY_POLICY_REVIEW_PRECURSOR_PENDING`
- `AUTHORITY_POLICY_REVIEW_CONFIRMATION_MISMATCH`
- `AUTHORITY_POLICY_REVIEW_EXPIRED`
- `AUTHORITY_POLICY_REVIEW_HANDLE_INVALID`
- `AUTHORITY_POLICY_REVIEW_ARTIFACT_MISMATCH`
- `AUTHORITY_POLICY_REVIEW_LOCKED`

Existing generic missing-role/consent/unknown-option failures may keep their
current codes before this branch. The unchanged generator must discover new
literal codes in the named Engineer files and produce their reference rows.
If the existing envelope/error classifier cannot express the above using the
named paths, return an exact amendment; do not silently edit a classifier, schema
or error table. A generator check failure is not waived.
