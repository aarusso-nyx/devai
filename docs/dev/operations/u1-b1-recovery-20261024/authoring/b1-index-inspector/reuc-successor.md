## Proposed bounded successor

At DEVAI commit `778edb9a20b46e854d96a45fb9778ef67b3d7824`, based on upstream `82ae9d9000d2ed71a7c38f4b3aa8f06bc2eabb2b`, the pure v2 index codec accepts at most one validated REUC extension and retains its exact signature, length, and payload bytes in the planned output. It continues to validate and discard TREE and rejects other extensions, duplicate REUC, malformed records, unsupported modes, missing or zero object IDs for nonzero stages, and duplicate REUC paths. It retains non-proof index-entry raw bytes and recomputes the Git index checksum; the public snapshot's semantic-entry projection excludes REUC and is unchanged, while its raw index hash binds the REUC bytes. Only the declared proof-chain entry is replaceable by this planner.

The admitted REUC path subset must satisfy the existing path validator, contain only printable ASCII, and be at most 4096 characters. ASCII case-folded exact matches of `record/proofs/chain.json` or `law/security/authorization.json` are refused; non-ASCII paths, including Unicode aliases, are refused. This deliberately excludes some valid ordinary Git paths. Screening provides the stated lexical checks only: it is **not** a universal proof of filesystem equivalence or of non-aliasing through symlinks, mounts, short names, or later host changes. The codec itself is pure and has no host authority. Opaque retention does not authorize restoring REUC entries, checkout, or any later Git operation.

The native phase 03 operation publishes the declared proof blob and performs the approved index CAS; it does not itself execute resolve-undo or checkout. Native reconciliation host binding admits Darwin/Linux runtime snapshots, while native provision's APFS check applies to the private root or Git directory. That check alone does not establish the filesystem of every working-tree path, especially for linked worktrees. A later operation must independently establish its own authority and host/path safety; retaining bytes now cannot establish a permanent future safety guarantee.
