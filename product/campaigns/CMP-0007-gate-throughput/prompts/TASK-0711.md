Role: Architect. Round R-0701, wave CTG-0711. Record: ADR-CHK-0007.
Tier: architect (resolve the host model from law/policy/model-tiers.json). Effort: high. Time budget: 60 minutes.

## Steps

1. Read ADR-CHK-0007 and ADR-CHK-0001, then law/schemas/test-task-descriptor.schema.json and docs/adopters/test-tasks.md.
2. Add the optional exclusivityKeys property to the task item of the descriptor schema exactly as rule 5 of ADR-CHK-0007 states it; change nothing else in the schema.
