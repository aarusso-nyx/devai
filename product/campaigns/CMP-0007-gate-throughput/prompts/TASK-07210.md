The ADR index is regenerated and law/policy/adr-validation.json is re-pinned.
- law/policy/credential-requirements.json declares the update-branch GitHub App credential the update workflow consumes. .devai/config/credential-requirements-binding.json binds it for this repository, as an Architect-owned adopter binding under the ADR-CHK-0008 path table. No credential value is committed.
