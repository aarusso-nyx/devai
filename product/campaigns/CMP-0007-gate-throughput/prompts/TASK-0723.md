# TASK-0723 Ship an opt-in pre-push hook that runs the commit-grammar range check and the affected check

Role: Engineer. Round R-0702, wave CTG-0723. Record: ADR-CHK-0001, ADR-GOV-0018.
Tier: worker (resolve the host model from law/policy/model-tiers.json). Effort: medium. Time budget: 120 minutes.

## Steps

1. Read the existing .githooks/commit-msg and .githooks/pre-commit and scripts/install-repository-hooks.mjs.
2. Write .githooks/pre-push and scripts/pre-push-preflight.mjs as the deliverables state, extend the installer, and add the integration test under tests/integration/.
3. Run the acceptance command.

## Boundary

Paths you may change:

- `.githooks/pre-push`
- `scripts/install-repository-hooks.mjs`
- `scripts/pre-push-preflight.mjs`
- `tests/integration/`

Forbidden:

- `law/`
- `.github/workflows/`

## Deliverables

- .githooks/pre-push runs scripts/pre-push-preflight.mjs, which fetches the base, runs scripts/check-commit-range.mjs over the pushed range, and runs check --affected --run against the fetched base; it refuses the push on a failure, names the failing node, and a BLOCKED probe names the environment fix.
- pnpm run hooks:install installs the hook alongside the commit-msg and pre-commit hooks without enabling it for a human who has not opted in, and an integration test covers a refused range and a clean push.

pnpm run test:root
