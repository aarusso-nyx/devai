# TASK-0712 Execute independent check plan nodes on a bounded worker pool under ADR-CHK-0007

Role: Engineer. Round R-0701, wave CTG-0712. Record: ADR-CHK-0007, ADR-CHK-0001.
Tier: worker-high (resolve the host model from law/policy/model-tiers.json). Effort: high. Time budget: 240 minutes.

## Steps

1. Read ADR-CHK-0007 in full; its ten numbered rules are the contract and its IA-001 to IA-008 are the tests.
2. Replace the sequential loop in packages/cli/src/services/check-runner/runner.ts with a scheduler that keeps the per-node disposition logic unchanged and assembles execution entries in plan order.
3. Add the --task-workers flag in packages/cli/src/commands/check/facade.ts and the worker option in the check-runner types; regenerate docs/reference/error-codes.md for CHECK_RUNNER_WORKERS.
4. Audit test-tasks.json for shared resources and declare exclusivity keys; never drop a node or a dependency.
5. Write the IA tests under packages/cli/tests/unit/ and run the acceptance commands.

## Deliverables

- The check runner schedules plan nodes on a pool of at most W workers by rules 1 to 10 of ADR-CHK-0007: dependency readiness, plan-order admission, conflict serialization by exclusivity key, overlapping output path, or the implicit db key, plan-order report and receipt assembly, unchanged per-task timeouts, and no cancellation on failure.
- check --run accepts --task-workers <n>, reads DEVAI_CHECK_TASK_WORKERS, defaults to min(4, availableParallelism()), refuses values outside 1..16 with CHECK_RUNNER_WORKERS before any node starts, and runs --rc, --release-intent, and protected execution sequentially; docs/reference/error-codes.md is regenerated for the new code.
- test-tasks.json declares an exclusivity key for every shared resource the audit of its nodes finds, and tests cover IA-001 to IA-008 of ADR-CHK-0007 with an injected executor.
