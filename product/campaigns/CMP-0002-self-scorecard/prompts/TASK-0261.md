# TASK-0261 Record the sweep, observe the head, and commit the first scorecard

Role: Inspector. Round R-0206, wave CTG-0261. Record: ADR-SCR-0001.
Tier: worker-high (resolve the host model from `models.tiers` in campaign.json). Effort: high. Time budget: 120 minutes.

## Steps

1. Declare the inspector role. Run `sense run --preset sweep --round R-0206 --as-role
inspector --write` from the repository root and record every reading with `sense
record --input <reading>`; then run `sense run build`, `unit_test`,
   `integration_test`, `e2e_test`, and `inventory_regeneration` the same way. Readings
   land under `.devai/state/sensor-readings/`; the inventory under
   `record/derived/inventory/`.
2. Run `audit observe --repo-root . --at <merged head> --round R-0206 --as-role
inspector --write`. Confirm the scorecard under
   `record/proofs/compliance/scorecards/` validates. Record it as measured: never edit a
   threshold, an override, or a reading; list every non-PASS cell with its finding in
   the campaign guide as a follow-up (the harness cells F5:T7, F5:T8, F5:T9 read live CI
   history and F3:T2 has no coverage run without a test database).
3. Replace HEAD_SHA in the acceptance command with the exact 40-character head you
   observed.
4. Record the scorecard id and the command sequence in `docs/dev/operations/self-
scorecard-campaign/README.md` and link the record from
   `docs/theory/framework/scorecard.md`.
