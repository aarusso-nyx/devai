# TASK-0234 Link every registered action from a use case so the coverage sensors measure the whole registry

Role: Architect. Round R-0203, wave CTG-0232. Record: ADR-SCR-0004.
Tier: architect (resolve the host model from `models.tiers` in campaign.json). Effort: medium. Time budget: 90 minutes.

## Steps

1. Read ADR-SCR-0004 and the R-0202 closure entry in the campaign guide: the plant and
   inventory coverage sensors now measure `law/policy/action-registry.json` against
   `refs.actionRefs[].id` in the mainFlow and alternateFlows steps of the use cases
   under `product/use-cases`, and 20 of the 61 actions are unlinked (audit, backlog,
   release, round tracking, triage classify).
2. Run `node .devai/state/pr-bootstrap/cli/bin.js sense run plant_coverage --repo-root .
--format json` and read the `PLANT_COVERAGE_UNLINKED_ACTION` findings for the exact
   list.
3. Extend `product/use-cases/devai-cli.json`, or add sibling use-case files under
   `product/use-cases/`, so each unlinked action appears in a flow step of the journey
   it serves. Write real operator journeys, not a catch-all step: an Auditor observing a
   head, an Engineer working the backlog, an Owner rehearsing and promoting a release, a
   round being tracked, a triage classification. Keep the use-case schema valid.
4. Rerun both coverage sensors and confirm `action_coverage_pct` is 100 and the status
   is pass.
