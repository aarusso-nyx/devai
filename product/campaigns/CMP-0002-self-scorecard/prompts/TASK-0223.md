# TASK-0223 Merge declared inputs into sensor runs and honor them in the sensors

Role: Engineer. Round R-0202, wave CTG-0221. Record: ADR-SCR-0005.
Tier: worker-high (resolve the host model from `models.tiers` in campaign.json). Effort: high. Time budget: 150 minutes.

Upstream: TASK-0222 must be merged; branch from its head.

## Steps

1. Read ADR-SCR-0005, the schema from TASK-0221, and the tests from TASK-0222.
2. In `packages/cli/src/commands/sense/shared.ts` add the resolver: load, validate
   against the installed schema, reject paths outside the repository, and merge with
   explicit `--input` taking precedence. Wire it through `run-set.ts` and `facade.ts` so
   `--dry-run` prints effective inputs.
3. Teach `packages/sensors/src/test-pattern-walker.ts` to accept test roots; `spec-
depth.ts` the ADR and invariants directories; `test-coverage-depth.ts` the coverage
   path; `action-effect-inference.ts` the effects tsconfig path; `type-check.ts` an argv
   override; `perf-test.ts` the script name. Defaults stay unchanged for adopters that
   declare nothing.
4. Rerun the sweep dry run and confirm the members list the effective inputs.
