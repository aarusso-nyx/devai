# TASK-0221 Declare the sensor inputs schema and the DEVAI inputs file

Role: Architect. Round R-0202, wave CTG-0221. Record: ADR-SCR-0005.
Tier: architect (resolve the host model from `models.tiers` in campaign.json). Effort: high. Time budget: 90 minutes.

## Steps

1. Read ADR-SCR-0005. Inputs are adopter declarations, never sensor defaults changed in
   code.
2. Create `law/schemas/sensor-inputs.schema.json` under the meta gate (draft 2020-12,
   `$id` under https://devai.nyxk.com.br/schemas/, example, `additionalProperties:
false`). Keys are sensor kinds from `law/policy/sensor-registry.json`; values are the
   declared inputs listed in the deliverables.
3. Create `.devai/config/sensor-inputs.json` with DEVAI's values and
   `law/policy/adopter-defaults/sensor-inputs.json` with an empty declaration set.
4. Add both file names to `SOURCE_ONLY_SCHEMAS` in
   `packages/cli/src/commands/check/schemas.ts`. That is the only code line you touch.
5. Write `docs/adopters/sensor-inputs.md` describing every key, its sensor, and the
   sweep outcome it changes.
