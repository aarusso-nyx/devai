# TASK-0133 Hooks, range checker, bump floor, changeset removal

Role: Engineer. Round R-0103, wave CTG-0103. Records: ADR-GOV-0018, ADR-REL-0027.
Upstream: TASK-0131 and TASK-0132 have landed. Make the tests green.

## Steps

1. `.githooks/commit-msg`: a node script validating the subject against
   `law/policy/commit-grammar.json`; the message lists the allowed types.
2. `.githooks/pre-commit` and `scripts/check-change-hygiene.mjs`: after
   lint-staged, classify staged paths through the change-taxonomy service (via
   the bootstrap CLI when the package is not built; document the fallback), reject
   cross-family sets and type-class disagreement, print every class found and a
   suggested `git add -p` split.
3. `scripts/check-commit-range.mjs <base> <head>`: walk first-parent commits after
   `historical_cutoff`, apply both rules, exempt merges and reverts, exit 1 naming
   each offending commit. Call it from `scripts/run-pr-release-gate.mjs` before
   the preflight run.
4. Bump floor in `scripts/run-pr-release-gate.mjs`: compute the maximum floor over
   the range, compare with the manifest version delta, and add
   `bump-floor-<level>` to the release intent blocking reasons when below it.
5. Remove `.changeset/`, `scripts/check-changesets.mjs`, the `changeset-version`
   case in `packages/cli/src/commands/check/adapters.ts`, and its row in
   `docs/reference/scripts.md`. Keep the yaml dependency. Remove a `package.json`
   script alias only if one references the removed script.
