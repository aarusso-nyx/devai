# TASK-0181 Interactive configuration contract

Role: Architect. Round R-0106, wave CTG-0108. Record: ADR-CFG-0001.
Tier: architect (resolve the host model from `models.tiers` in campaign.json). Effort: high. Time budget: 90 minutes.

## Steps

1. `docs/adopters/interactive-configuration.md`: the contract page. Two modes
   that never mix: bind or re-bind (materializes from the installed package) and
   edit (adopter-owned keys only). List the adopter-owned keys by reading
   `law/schemas/project-config.schema.json` and the binding files under
   `.devai/config`; list the materialized files that edit mode refuses, taken from
   `scripts/check-policy-materialization.mjs`. State the replay guarantee: the
   flow ends by printing the exact non-interactive argv it executed. State the
   no-terminal behavior: structured error, no write.
2. `law/policy/action-registry.json`: extend the `init plan` description to
   mention the interactive flag. No effect, capability, consent, or authority
   field changes. Run `pnpm run devai:prepare` and commit the generated views
   (`packages/cli/src/generated/action-registry.ts`,
   `packages/effects-check/src/generated/action-catalog.ts`,
   `packages/sensors/src/generated/action-kinds.ts`) with the registry.
3. `docs/adopters/install.md`: point at the interactive path as an alternative
   to hand-assembled flags.
