# TASK-0151 Credential requirements manifest

Role: Architect. Round R-0104, wave CTG-0105. Record: ADR-SEC-0001.
Upstream: wave CTG-0104 is merged.

## Steps

1. `law/schemas/credential-requirements.schema.json`: entries of `id`, `kind`
   (environment, repository-secret, environment-secret, gh-auth, file), `scope`
   (free text such as `read:packages`, `issues:write`, `signing`), `consumer`
   (workflow file and job, or action id), `absence` (block, degrade), and
   `description`. Meta gate rules apply.
2. `law/policy/credential-requirements.json`: DEVAI's manifest. Enumerate every
   `secrets.*` reference in `.github/workflows/release.yml` and
   `devai-ledger-verify.yml`, the `PACKAGES_READ_TOKEN` named in
   `law/policy/trusted-local-rc-verifier-package.json`, the `NODE_AUTH_TOKEN`
   from `docs/adopters/install.md`, and `GITHUB_TOKEN` uses. Never write a value.
3. `law/policy/adopter-defaults/credential-requirements-binding.json`: the
   adopter starting set (package read token, optional issues write).
4. Catalogue the schema in `SOURCE_ONLY_SCHEMAS` in
   `packages/cli/src/commands/check/schemas.ts`.
5. `docs/adopters/install.md`: a "Required credentials" section generated by hand
   from the manifest. `docs/dev/security/secret-handling.md`: the boundary
   statement: presence, shape, and scope verified; values never read, stored,
   or generated by DEVAI.
