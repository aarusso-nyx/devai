# TASK-0171 Backlog actions and item contract

Role: Architect. Round R-0105, wave CTG-0107. Record: ADR-GOV-0019.
Tier: architect (resolve the host model from `models.tiers` in campaign.json). Effort: high. Time budget: 90 minutes.

Naming note: `packages/loop/src/loop/backlog.ts` already implements the round
task queue behind `task queue`. The new family is the repository backlog; keep
the action ids `backlog add`, `backlog list`, `backlog show`, `backlog resolve`
as the record states, and name the new module `repository-backlog` so the two
never collide.

## Steps

1. `law/policy/action-registry.json`: four stable entries with `effect`
   local-write, capabilities `fs:f5-state` and `proc:git`, the same authority and
   consent shape as `round gap create`, an optional `--round` that is never
   inferred, and complete `output_contract` and `error_contract` blocks. Update
   `counts`. Run `pnpm run devai:prepare` and commit the regenerated views
   (`packages/cli/src/generated/action-registry.ts`,
   `packages/effects-check/src/generated/action-catalog.ts`,
   `packages/sensors/src/generated/action-kinds.ts`) with the registry in the
   same commit.
2. `law/schemas/backlog-item.schema.json`: `id` `^BL-[0-9]{4,}$`, `kind`
   (finding, proposition, note, flaky-test), `class` (taxonomy class, optional),
   `title`, `body`, `origin` (session id, role, commit), `round_id` (optional),
   `status` (open, resolved), `resolution` (reference, optional).
   `law/schemas/backlog-list-output.schema.json` for the list payload.
3. `law/policy/github-issues-tracking.json` and
   `law/schemas/github-issues-tracking-policy.schema.json`: add event kind
   `backlog_item_projected` and a `backlog_projection` block reusing the
   disclosure profile.
4. `.devai/config/toolchain.json`: set `constants.expected_action_count` to the
   new total.
5. `docs/adopters/governance-tracking.md`: a section on backlog projection.

## Acceptance

```bash
pnpm run devai:prepare
pnpm run action-registry:check
node .devai/state/pr-bootstrap/cli/bin.js check --only schemas --format json
```
