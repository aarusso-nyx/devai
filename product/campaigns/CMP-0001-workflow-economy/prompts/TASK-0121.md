# TASK-0121 Change class taxonomy policy, schema, bindings

Role: Architect. Round R-0102, wave CTG-0102. Record: ADR-GOV-0017.

## Steps

1. `law/schemas/change-taxonomy.schema.json`: `classes` is a closed enum of
   law, spec, plan, code, tests, docs, ci, toolchain, generated. Each class
   declares `family` (governance, implementation, infrastructure),
   `check_members` (names that exist in the member switch of
   `packages/cli/src/commands/check/adapters.ts`), and `constitution_authority`
   (the Article 6 row it maps onto). `pairings` lists `{classes: [a, b], reason}`.
   A separate `bindings` section is ordered entries of
   `{selector: {kind: exact|prefix|glob, pattern}, class}`; overlap is a load
   error, never a precedence rule, and the description says so.
2. `law/policy/change-taxonomy.json`: include the law plus generated pairing with
   the reason that the action registry and its generated views must co-commit.
   Map plan to `record/`, `work/`, `product/`; law to `law/`; spec to
   `law/invariants/` and `law/schemas/`; tests to `tests/` and
   `packages/*/tests/`; generated to every path in the registry's
   `generated_views`.
3. `.devai/config/change-taxonomy-binding.json` must classify every path in
   `git ls-files`; `law/policy/adopter-defaults/change-taxonomy-binding.json`
   carries a starting binding for adopters.
4. `law/schemas/test-task-descriptor.schema.json`: add `class` to the selector
   kinds with its pattern restricted to the class enum.
5. `law/policy/round-execution.json` declares `coupled_order` inspector first,
   while `docs/roles/cross-role-coordination.md` and Constitution Article 24
   order Architect first. Make them agree with the constitution and record the
   reason in one paragraph. If Owner input is required, stop and report.
6. Add both schema names to `SOURCE_ONLY_SCHEMAS` in
   `packages/cli/src/commands/check/schemas.ts`, add the taxonomy policy to
   `scripts/check-policy-materialization.mjs`, and add a section to
   `docs/adopters/ci-economy.md`.
