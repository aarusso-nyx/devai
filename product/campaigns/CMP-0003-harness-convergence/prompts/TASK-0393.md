Tier: worker-high (resolve the host model from `models.tiers` in campaign.json). Effort: high. Time budget: 150 minutes.

Upstream: TASK-0392 must be merged; branch from its head.

## Steps

1. Read ADR-CHK-0005 and the tests merged by TASK-0392; branch from the inspector head.
2. In packages/cli/src/commands/check/adapters.ts and adapters-reports.ts, read each
   member's declared applicability, detect the repository kind from the bound project
   configuration, and return the structured not-applicable result for a self-only
   member in an adopter; replace the forced scope in the runActionCoverageCheck call
   with the detected scope and report an empty adopter population explicitly.

   --only, machine JSON, and human output agree; regenerate docs/reference/error-codes.md
   with scripts/generate-error-code-reference.mjs after adding the code in source.
5. Rebuild, run release:bootstrap, and run the acceptance commands.
