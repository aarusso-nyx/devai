# Product contracts

The current product surface is the CLI use-case model and its adopter journey cases.
Historical Owner mandates used to govern DEVAI's own development are not shipped in the
release-candidate tree.

- `use-cases/devai-cli.json` describes the supported CLI interactions, including the
  journey cases that walk an adopter through the registered actions.
- `campaigns/` holds the campaign ledgers and their planning records, one directory per
  campaign (`CMP-NNNN-<slug>/`).
- `stories/` and `rules/` are reserved for adopter-owned product material.

Human maintainers, not DEVAI, decide changes and releases for this repository.
